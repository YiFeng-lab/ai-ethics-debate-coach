## 我的工作

- 对话设计：定义角色、任务和行为规则，设计“提出观点 → 追问与反驳 → 权衡 → 反思”的流程，以4–5轮为目标。
- 知识与提示词：选择 AI 治理与 AI 素养材料，调整提示词和语气，让追问保持挑战性与支持性。
- 使用体验：配套设计学习活动，并将 Odin 聊天工具嵌入网页。
